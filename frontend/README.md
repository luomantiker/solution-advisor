# 前端工作台使用说明

前端以第一版工作台为基准：深海军蓝左侧导航、宽白色内容画布以及既有页面信息架构保持稳定。所有业务数据仍由后端授权和 ViewModel 决定，前端不会把用户输入转换为 Shell、Docker、SSH、路径、凭据或 Worker 选择。

## 导航与辅助区

- 所有人可使用“上传”和“模型列表”。普通用户不能看到也不能通过路由进入平台治理、人员管理。
- 管理员可进入平台治理；超级管理员额外可进入人员管理。
- 左下“通知”仅在用户主动打开时读取已经持久化的、脱敏的账号、评估和平台审计事实；它不创建 WebSocket、SSE 或全局轮询。没有可显示事件时会明确显示空状态。
- 左下“帮助”按当前页面和角色显示版本化帮助内容；侧栏收起后所有入口仍保留图标、可访问名称和 tooltip。

## 账号与协作边界

新建本地人员与重置密码默认使用 `Realthon_1`，账号直接为 `ACTIVE`，不强制首次改密。用户仍可主动改密；成功后现有会话会失效，需重新登录。

Candidate 是无期限人工认领：未认领项可由 ACTIVE 管理员领取；认领人可编辑、测试、推进或手动释放。释放会清理该次接入资料。其他管理员只读，后端写操作返回 `423`；超级管理员可带原因强制释放，或清理后指定一名 ACTIVE 管理员。页面不显示租约、续租、倒计时或自动超时语义。
