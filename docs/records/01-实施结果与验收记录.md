## 已完成能力

1. ONNX 上传、SHA-256 内容寻址、解析校验、ModelAsset / ModelProfile 持久化及 `onnx_sha256 + analyzer_version` 缓存复用。
2. 平台无关的 ONNX 事实分析：IR/opset、I/O、shape、节点、算子统计和结构标记；不包含芯片支持性或优化结论。
3. Vue Web Portal：上传、模型列表、Model Profile 详情、DEMO 多平台任务创建、任务详情、报告在线预览与 Mock PDF 下载。
4. `EvaluationTask.mode` 保存 `DEMO | REAL` 语义；本阶段创建 API 只接受 `DEMO`，`REAL` 返回 422。
5. X5/S100/Intel 示例结果仅从 `src/solution_advisor/evaluations/fixtures/demo_results_v1.json` 读取，并保留 fixture 版本；没有 Worker ID、板卡命令、编译日志、性能数据或真实性能证据。
6. 报告 ViewModel 固定包括：多平台评估结论摘要、一次 ONNX 模型检测概要、各平台适配与板端测试结果、后续优化建议、版本与证据附录。Web 与 PDF 均由同一 ViewModel 驱动；页面、报告和 PDF 标识 `Mock / 不可用于交付结论`。

## 页面访问方式

本地启动：

```bash
uv sync --all-extras
uv run uvicorn solution_advisor.api.app:app --host 127.0.0.1 --port 8000
```

访问路径（本次未生成二进制截图，以下路径为可复现页面验收入口）：

- `http://127.0.0.1:5173/`：Vue 开发服务器的 ONNX 上传页。
- `http://127.0.0.1:5173/models`：模型列表。
- `http://127.0.0.1:5173/models/{asset_id}`：Model Profile 详情。
- `http://127.0.0.1:5173/tasks/new?profile_id={profile_id}`：DEMO 任务创建。
- `http://127.0.0.1:5173/tasks/{task_id}`：DEMO 任务详情、报告预览与 PDF 下载。
- Compose 部署入口为 `http://127.0.0.1:8080/`；FastAPI API 为 `http://127.0.0.1:8000/`。
- `http://127.0.0.1:8000/api/v1/reports/{task_id}/download`：生成的 Mock PDF HTTP 路径。

## 与设计或任务文档的差异

- Portal 从 FastAPI 服务端 HTML 迁移为独立 Vue 3 + TypeScript + Vite 项目；前端有独立 `npm ci`、类型检查和生产构建，FastAPI 不再返回 HTML。

## 已知限制

- 不支持创建或执行 REAL 任务；没有 Worker、Docker 工具链、Conda、SSH、板卡或编译/实测接入。
- DEMO 结果是静态 fixture，不能产生推荐部署、已实测、性能排序或正式交付结论。
- 当前开发数据后端为 SQLite 与本地文件，生产环境需要替换为受管数据库和对象存储。
