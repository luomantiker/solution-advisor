# 报告模块

本目录将受控评估的持久化事实组织为页面报告和 PDF。报告只描述已有 Artifact、Evidence、
阶段结果和冻结快照，不生成或推测不存在的性能结论。

## 报告入口

- 单个平台历史任务：保留兼容的任务报告入口。
- `EvaluationFlow`：用户侧多平台报告入口；只展示该 Flow 实际选择的平台，并取每个平台
  最终可达阶段作为汇总依据。

Flow PDF 至少包含：评估范围与边界、ONNX 模型摘要、各平台最终阶段、制品格式、固定
Runner、解析器、可用的固定条件实测指标和未验证边界。

## 事实与边界

- X5 与 S100 的 Runner、制品格式、解析器、Evidence 和性能数据保持隔离。
- 输入、线程、帧数、Runtime 等条件未对齐时，报告不得进行无条件 FPS 或延迟排名。
- 输出一致性、任务精度、稳定性、功耗和部署推荐，除非存在对应独立 Evidence，均显示为
  “未执行”或“未验证”。
- DEMO 报告必须保留 Mock 标识，不得混入 REAL Artifact 或板端结论。

PDF 采用可提取中文文本，供用户下载和审计；Artifact/Evidence 的下载权限仍由 API 的
所有权和分享授权控制。
