## M5-A-R1 准入门槛

只有下列材料齐备，才可开始真实 S100 Platform Package、固定 Runner 与接入测试：

1. 由管理员显式创建的 Candidate，且 Host 已发现用于该平台版本的镜像；若与 Catalog 参考 digest 不同，
   必须由管理员确认并保留告警与实际镜像追溯；
2. 在锁定镜像内实际自检并保留 Evidence，确认已声明的 `hb_compile --fast-perf --march nash-e --model <input_onnx>`、许可证和真实产物格式；
3. 在板端实际自检并保留 Evidence，确认已声明的 `hrt_model_exec perf`、Runtime 版本、模型下发方式、输出及设备访问要求；
4. 可离线回归的版本化 ONNX fixture、来源与许可证；
5. 受审查的 Platform Package、镜像锁、固定 Runner、自检和离线 Evidence；
6. 管理员审核记录后发布 PlatformCatalog，才允许建立 Binding 与 READY Worker。
